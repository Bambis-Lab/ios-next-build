# iOS Next 1.6.0 · Factory Command Deck (Build 23)

## Native Factory, komplett vor der ersten Verbindung nutzbar
- Eigene SwiftUI-Topologie für Factory, Owner, Runner und Runtime, keine neuen Tabs im Home-Assistant-Dashboard.
- Lesende Projekt-, Job-, Governance- und Diagnoseansichten; leere, Offline-, Lade- und Fehlerzustände sind ohne Backend zugänglich.
- Vorbereitete direkte Factory-MCP-Anbindung: Protected Resource Metadata, Authorization Server Discovery, OAuth 2.1 mit PKCE-S256, dynamische Client-Registrierung oder manuelle öffentliche Client-ID, Systembrowser, Token-Refresh und Keychain.
- Strikte Read-only-Tool-Allowlist. Keine frei konfigurierbaren Tools, Shellbefehle oder neuen Schreibaktionen.
- MCP JSON-RPC / Streamable HTTP mit Initialisierung, Tool-Inventar, paginierten Tools und sicheren Quell-Snapshots.

## Ruhigeres Apple-Design
- Anpassungen sämtlicher vorhandener Hintergrundfamilien (Home/Räume, App/Management, Owner/Runner/Factory); Farben und Raumzuordnung bleiben erhalten.
- Dezentere statische Verläufe, automatisch Light-/Dark-adaptiv; bei 'Transparenz reduzieren' opake Systemflächen.
- Custom Factory Command Deck ohne endlose Animation oder kostenintensives Blur-Layering.

## Grenzen
- Kein Zugriff auf Live-Factory vor tatsächlicher Nutzeranmeldung. Live-OAuth-/Netzwerkfunktion wird erst nach Konfiguration auf dem Gerät verifiziert.
- Bestehende Home Assistant-, Medien-, Licht-, Fire TV-, Jarvis- und Chat-Funktionen bleiben unverändert.
- Vorbereitete **unsignierte** Device-IPA für anschließendes SideStore-Signing, kein automatisches Deployment.
