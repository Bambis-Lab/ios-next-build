# iOS Next 1.2.1

## What's New

- Owner Releases now shows the installed iOS Next version from the running app bundle instead of trusting a potentially stale backend inventory value.
- When backend release inventory disagrees with the running app, the UI marks the mismatch instead of presenting the stale value as authoritative.
- Version bumped to 1.2.1 (17) for the SideStore patch release.

## Scope

This is a stabilization patch on top of 1.2.0. It does not enable new write capabilities or host-control actions. Master/Governance integration remains read-only in this release.

## Rollback

The previous public release 1.2.0 (16) remains the rollback target.
