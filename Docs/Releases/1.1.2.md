# iOS Next 1.1.2 (Build 15)

Release candidate based on `fix/1.1.2-runtime-firetv`.

## Inhalt

- Master Runtime verwendet den gemeinsamen Runner-/Master-Live-Kontext statt einer separaten Live-Konfiguration.
- Die sichtbare Runtime-Darstellung ist vollständig auf Master Runtime ausgerichtet; Legacy-Telemetrie bleibt nur als interner Kompatibilitätsadapter erhalten.
- Home-Assistant-Topologie-Lookups verwenden einen vorberechneten Index für geringeren Laufzeitaufwand.
- Fire-TV-Media-Karten verwenden die neue V2-Presentation mit konsistenten Player-, Lautstärke-, Queue-, Wake- und Standby-Zuständen.
- Interne Fire-TV-Systempakete und Service-Prozesse werden nicht mehr als nutzerrelevante Apps oder Now-Playing-Inhalte angezeigt.
- Now Playing wird nur noch dargestellt, wenn tatsächlich nutzerrelevante aktive Medien- oder Playback-Daten vorliegen.
- Regressionstests decken Master Runtime, Live-Session und Fire-TV-Verhalten für 1.1.2 ab.

## Build-Gate

- Xcode 27 / iPhoneOS 27.0
- Release, ARM64
- Bundle-ID `de.nicofroeba16.iosnext`
- Version `1.1.2`
- Build `15`
- Free-Sideload-Build ohne PacketTunnel-Extension
- Bestehende akzeptierte Motion-Baseline bleibt unverändert.

## Rollback

Der kanonische Rückfall bleibt die zuletzt freigegebene funktionierende SideStore-Version, bis 1.1.2 vollständig gebaut, geprüft und veröffentlicht wurde.
